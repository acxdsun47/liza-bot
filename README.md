# Бот для Лизы

Делает несколько вещей:

1. Присылает три сообщения-напоминания о любви в день:
- **08:00** — «Доброе утро, любимая🩷»
- **около обеда** (случайное время между 12:00 и 14:00) — «Я тебя люблю, лизочка»
- **23:00** — «Самых сладких снов, любимая»
1. **5 раз в день спрашивает о самочувствии** (утро, перед обедом, обед, после обеда, ночь — точное время в `MOOD_CHECKIN_TIMES` в `main.py`) и сохраняет ответы в файл `mood_log.jsonl`.
1. **По воскресеньям в 20:00** присылает сводку самочувствия за неделю (составлена ИИ на основе сохранённых ответов) — можно показать партнёру или психологу.
1. В остальное время — тёплый поддерживающий собеседник (через cheapai.io, не замена психотерапевту), умеет предлагать **практики при тревоге, стрессе и панических атаках** (дыхательные техники, заземление, мышечная релаксация).
1. **Понимает напоминания**: если написать «напомни в 15:00 сделать задание» — пришлёт сообщение ровно в это время.
1. Понимает голосовые сообщения — распознаёт речь и отвечает на то, что было сказано.

## Установка

```
pip install -r requirements.txt
```

Если `pip` не находится в Windows, используй `py -m pip install -r requirements.txt`.

### Для распознавания голосовых сообщений нужен ffmpeg

Это отдельная программа (не через pip), она конвертирует голосовые файлы Телеграма перед распознаванием. Без неё голосовые сообщения не заработают (текст и три ежедневных сообщения будут работать в любом случае).

**Windows:**

1. Скачай архив: <https://www.gyan.dev/ffmpeg/builds/ffmpeg-release-essentials.zip>
1. Распакуй в `C:\ffmpeg` (чтобы получилось `C:\ffmpeg\bin\ffmpeg.exe`)
1. Добавь `C:\ffmpeg\bin` в переменную PATH: Пуск → «Изменение переменных среды» → «Переменные среды» → в списке «Path» → «Изменить» → «Создать» → вставь `C:\ffmpeg\bin` → ОК везде
1. Открой новое окно терминала и проверь: `ffmpeg -version` — должна показаться версия, а не ошибка

**Mac:** `brew install ffmpeg`
**Linux:** `sudo apt install ffmpeg`

## Настройка

1. **Токен бота**: напиши [@BotFather](https://t.me/BotFather) в Телеграме, команда `/newbot`, следуй инструкциям — получишь `BOT_TOKEN`.
1. **Ключ cheapai.io**: зарегистрируйся на <https://cheapai.io/en/register>, в личном кабинете зайди в раздел Keys → Create, скопируй ключ вида `sk-...`. Это `CHEAPAI_API_KEY`. Пополни баланс (минимум $5 или 200₽) — без баланса ключ вернёт ошибку авторизации.
1. **ID чата с Лизой** (`TARGET_CHAT_ID`):
- Попроси Лизу написать что угодно твоему новому боту в Телеграме.
- Открой в браузере: `https://api.telegram.org/bot<ТВОЙ_ТОКЕН>/getUpdates`
- Найди в ответе `"chat":{"id": ЧИСЛО, ...}` — это и есть нужный ID (может быть отрицательным, это нормально).
1. Задай переменные окружения.
   
   **Важно для Windows (cmd)**: каждая команда `set` — на своей отдельной строке, Enter после каждой.
   
   Windows (cmd):
   
   ```
   set BOT_TOKEN=1234567:AAA...
   set CHEAPAI_API_KEY=sk-...
   set TARGET_CHAT_ID=935428939
   ```
   
   Linux/macOS:
   
   ```bash
   export BOT_TOKEN="1234567:AAA..."
   export CHEAPAI_API_KEY="sk-..."
   export TARGET_CHAT_ID="935428939"
   export TIMEZONE="Europe/Moscow"
   ```

## Запуск

```
python main.py
```

(на Windows, если стоит несколько версий Python — например `py -3.12 main.py`)

Бот будет работать, пока запущен процесс, и **в том же окне терминала**, где заданы переменные `set`/`export` — они не сохраняются между окнами.

## Перенос на сервер (Railway) — чтобы работал 24/7 без компьютера

Всё делается в браузере (можно и с телефона), без командной строки.

1. **GitHub**: зарегистрируйся на github.com → New repository → назови, например, `liza-bot` → Add file → Upload files → загрузи **все файлы из этой папки**: `main.py`, `requirements.txt`, `Procfile`, `nixpacks.toml` → Commit changes.
1. **Railway**: зайди на railway.app → зарегистрируйся через тот же GitHub-аккаунт → New Project → Deploy from GitHub repo → выбери `liza-bot`. Railway сам увидит `Procfile` и `nixpacks.toml` (он ставит ffmpeg — нужен для голосовых) и запустит сборку.
1. **Переменные окружения**: в проекте на Railway открой вкладку **Variables** → добавь по одной:
- `BOT_TOKEN`
- `CHEAPAI_API_KEY`
- `TARGET_CHAT_ID`
- `TIMEZONE` = `Europe/Moscow` (можно не добавлять — это и так значение по умолчанию)
   
   После сохранения любой переменной Railway перезапустит бота автоматически.
1. Проверить, что всё работает — вкладка **Deployments** → открой последний деплой → **View logs**: там должна появиться строка `Бот запущен`, как раньше в cmd.

**Важно про файл с настроением (`mood_log.jsonl`)**: по умолчанию Railway на бесплатном тарифе может сбрасывать файлы при пересборке проекта (например, после того как ты поменяешь код). Если хочешь, чтобы записи о самочувствии копились надёжно и не терялись — на Railway есть платная функция **Volumes** (постоянное хранилище), это отдельная настройка, скажи, если понадобится — подключим отдельно.

## Важно

- Все времена (08:00, коридор 12:00–14:00, 23:00) считаются в часовом поясе из `TIMEZONE` (по умолчанию Москва). Поменять коридор или часы можно в начале `main.py` — константы `MORNING_TIME`, `MIDDAY_WINDOW_START/END`, `EVENING_TIME`.
- Случайное время обеденного сообщения выбирается заново каждый день (в 00:05 по `TIMEZONE`), поэтому оно не повторяется день в день.
- Тексты сообщений и системный промпт “психолога” — в файле `main.py`, легко редактируются под себя.
- Модель задана переменной `CHEAPAI_MODEL` (по умолчанию `claude-sonnet-4-6` — хорошее сочетание цены и качества). Другие варианты (Claude Opus 5, Claude Haiku и т.д.) — на <https://cheapai.io/en/models>
- Бот-собеседник — это поддержка в моменте, а не замена психотерапевту. В системном промпте это учтено: при признаках серьёзного кризиса бот мягко предложит обратиться к специалисту.
- Распознавание голоса бесплатное (через Google), но требует интернет-соединения на сервере/компьютере в момент отправки голосового и точно требует установленного ffmpeg (см. выше). Работает лучше на коротких голосовых (до ~1 минуты).
- Ответы о самочувствии сохраняются в файл `mood_log.jsonl` рядом с `main.py` (путь можно поменять через `MOOD_LOG_PATH`). Это обычный текстовый файл — можно открыть и почитать вручную.
- Время вопросов о самочувствии, время сводки и её день недели — константы `MOOD_CHECKIN_TIMES`, `WEEKLY_SUMMARY_TIME`, `WEEKLY_SUMMARY_DAY` в начале `main.py`.
- Напоминания понимаются в свободной форме («напомни в 15:00 сделать задание», «в 9 вечера напомни принять витамины») — модель сама достаёт время и текст. Если бот один раз не поймёт формулировку — можно попросить чуть конкретнее, указав час и минуту.
- Напоминания и вопросы о самочувствии хранятся только в оперативной памяти запущенного процесса — если перезапустить бота, уже поставленные на сегодня напоминания и невыполненные чек-ины из прошлого запуска пропадут (сохранённые в файл ответы о самочувствии — не пропадают).
